## Information Literacy Reflection

I have received incorrect answers from AI tools when the answer sounded
confident but was based on an older version of a library. In one case, a
suggested method did not exist in the version used by my project. Checking the
official documentation and testing the smallest example helped me find the
version mismatch.

When I evaluate a resource, I check who published it, when it was updated, and
whether it matches my language, framework, browser, and project versions. I
prefer official documentation for API behavior and use tutorials or AI as
additional explanations. I also look for working examples, compare multiple
sources, and verify the answer by running a small test instead of trusting a
confident explanation on its own.
